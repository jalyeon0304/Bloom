# 급전지시 모니터링 구현 전 확인 질문

아래 질문을 먼저 확정하면, 바이브 코딩으로 빠르게 MVP를 만들 수 있습니다.

## 1) Webview 접근/인증
- VPN 연결 방식은? (항상 연결 / 작업 시간대만 연결)
- 로그인 방식은? (ID/PW, SSO, OTP, 인증서)
- 세션 만료 주기와 재로그인 조건은?
- 봇 탐지(캡차, 2차 인증)가 있는가?

## 2) [급전지시] 이벤트 정의
- 화면에서 정확히 어떤 문구/코드가 "급전지시" 인가?
- 이벤트 발생시각 기준은? (표시시각/서버시각/수신시각)
- 동일 이벤트 재공지 시 중복으로 볼지, 갱신으로 볼지?
- 이벤트 취소/정정 케이스가 있는가?

## 3) 발전량 데이터
- 발전량 단위(MW/kW)와 소수점 자릿수는?
- 발전소/호기 식별자는 무엇인가?
- 이벤트 발생 직전/직후 몇 분 데이터를 기록할지?
- 결측 데이터 발생 시 대체 규칙이 필요한가?

## 4) 운영 요구사항
- 실시간성 목표: 몇 초/분 지연까지 허용?
- 알림 채널 필요 여부: Slack, Teams, 문자, 이메일
- 사용자 권한 분리 필요 여부(조회/관리자)
- 데이터 보관 기간(예: 1년/3년)

## 5) 배포/보안
- 실행 위치: 개인 PC / 사내 서버 / VM
- DB 설치 가능 여부(PostgreSQL 가능?)
- 자격정보 저장 방식(.env, 사내 비밀관리도구)
- 감사로그(누가 언제 조회/다운로드) 필요 여부
