# 운영 전 "빈부분" 체크리스트 (현재 코드 기준)

이 문서는 "지금 로직에서 내가 추가로 채워야 할 부분"을 빠르게 확인하기 위한 목록입니다.

## A. 반드시 채워야 하는 도메인 입력값
1. **site 마스터 데이터 최신화**
   - 현재 `src/bloom/stamp_capacity.tsv` 기반으로 site 집계 자동 생성
   - 엑셀 변경 시 TSV 갱신 필요
2. **비중앙 target 규칙 확정**
   - `target_pct` 기본값(0/40/60) 적용 정책
   - 시간 내 도달 판정 시 "이하" 기준이 맞는지 최종 확인
3. **준중앙 target-time 정책**
   - min/max 각각의 target time 기본값
   - target-time OFF 허용 여부

---

## B. 코드상 데모에서 운영으로 바꿔야 하는 부분
1. **인메모리 저장소 -> DB 영속화**
   - `_ACTIVE_CONFIGS`, `_OPEN_OUTPUTS`, `_SEMI_PROGRESS`를 DB로 이동
2. **수집기 실제 구현**
   - `src/bloom/crawler/webview_client.py`는 현재 골격이며 실제 로그인/파싱 로직 없음
3. **인증 보안 강화**
   - 승인형 인증은 데모 수준(인메모리)
   - JWT 서명키, 감사로그, 세션 폐기 정책 필요
4. **장애/재시작 복구**
   - 서버 재시작 시 시초값/도달시각 복원 로직 필요

---

## C. 화면/운영 정책에서 확정 필요한 것
1. 판정 시각
   - 초당/분당 평가 주기
2. 경보 정책
   - 시초-제출 10% 외 추가 경보 여부
3. 다운로드 규격
   - CSV/XLSX 필수 컬럼, 정렬, 시간대
4. 권한 정책
   - 조회자/운영자/관리자 권한 분리

---

## D. 서버 PC 설치 후 바로 하는 점검 순서
1. `curl /health`
2. `curl /api/master-sites`
3. 대시보드 접속
4. site +추가 (준중앙/비중앙 각 1개)
5. 프로그램 시작(시초기록)
6. 판정/경보 값 확인

---

## E. 지금 사용자(당신)가 주면 바로 구현 가능한 항목
- 최신 stamp 데이터(엑셀/TSV)
- 비중앙 target_pct 기본값(현장별 예외 포함)
- 준중앙 min/max target time 기본값(site별 예외 포함)
- CSV/XLSX 양식 샘플(있으면 가장 빠름)
