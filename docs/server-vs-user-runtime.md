# 서버 PC 설치 시/사용자 PC 설치 시 구동 모습

질문: "서버 PC에 설치하면 어떻게 되고, 사용자 PC에 설치하면 어떤 모습으로 구동되는지"

## 결론 요약
- **서버 PC(VPN 가능)**: 데이터 수집 + API/대시보드 제공 주체
- **사용자 PC(VPN 불가 가능)**: 브라우저에서 대시보드 접속/조회 주체
- 즉, 운영은 서버 1대 중심이고 사용자 PC는 웹 클라이언트 역할입니다.

---

## 1) 서버 PC에 설치하면

### 설치 후 서버가 하는 일
1. FastAPI 앱이 8000 포트로 실행됨
2. `/api/*` 엔드포인트 제공
3. `/dashboard` 화면 제공
4. (향후) VPN을 통해 Webview 크롤링 수행

### 서버 PC에서 보이는 것
- 터미널: uvicorn 실행 로그
- 브라우저:
  - `http://127.0.0.1:8000/health` (상태 확인)
  - `http://127.0.0.1:8000/dashboard` (대시보드)

### 서버 PC에서 초기 설정(운영자)
- 현장 +추가(활성화)
- 준중앙: 제출/min/max (+ 필요 시 min/max target time)
- 비중앙: 제출/target%/제한시간
- 프로그램 시작(시초기록)

---

## 2) 사용자 PC에 "설치 없이" 접속하면 (권장)

### 사용자 PC가 하는 일
- 브라우저로 서버 URL 접속
- 조회/모니터링/다운로드
- 로직 계산은 서버가 수행하고 사용자 PC는 결과만 봄

### 사용자 PC에서 보이는 것
- 서버와 동일한 `/dashboard` 화면
- 그래프, 표, 경보 하이라이트
- 탭(전체/준중앙/비중앙) 전환 가능

> 권장: 사용자 PC에는 앱 설치 대신 URL 접근 방식 사용.

---

## 3) 사용자 PC에 프로젝트를 직접 설치해서 실행하면?
- 기술적으로는 가능하지만 권장하지 않음
- 이유:
  - 운영 기준이 분산됨(버전 불일치 위험)
  - 사용자 PC는 VPN/Webview 접속 조건이 다를 수 있음
  - 중앙 승인/감사로그/통제 관점에서 불리함

즉, **서버 1대 운영 + 사용자 다수 웹 접속** 모델이 맞습니다.

---

## 4) 실제 체감 UI 흐름 (사용자 관점)
1. 대시보드 접속
2. 그룹 탭 선택
3. site별 실시간 그래프 확인
4. 표에서 판정 확인
   - 준중앙: min/max ±5% 또는 target-time 모드 결과
   - 비중앙: target% 시간 내 도달 여부
5. 시초-제출 편차 10% 이상은 빨간 경고 행 확인

---

## 5) 운영 추천
- 서버 PC: 설치/실행/수집 담당
- 사용자 PC: URL 접속 전용
- 서버만 systemd로 상시 실행 고정
