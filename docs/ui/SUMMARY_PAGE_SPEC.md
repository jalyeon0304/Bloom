# Summary Page Spec

## Goals
- KST 기준 “오늘 날짜”가 기본 선택된다.
- 5초 안에 현재 상황(차트 + 활성 현장)을 파악할 수 있어야 한다.
- 문제 타입 판정(감발지연 등)은 v0에서는 제외한다.

## Pages
- Summary: /summary (또는 기존 /dashboard 대체 가능)
- UI preview: /ui-kit (fixture 기반)

## Time & Date
- Timezone: Asia/Seoul (KST)
- X-axis time window is fixed:
  - start: 09:00
  - end: 17:00
- Date default: serverDateKst (접속일 기준)

## Chart
### Modes
- Default: Per-site lines (옵션B)
- Optional toggle: Aggregated (옵션A) - vNext

### Series selection
- Group checkbox:
  - Semi-central ALL: selects all semi sites (fixed 4)
  - Non-central ALL: selects all active non-central sites of the day (isActive && !isCanceled)
- Per-site checkbox for each row.
- Final plotted set = union of selections.
- Group checkbox supports tri-state (checked/indeterminate/unchecked).

### Axes
- X-axis: 09:00~17:00 fixed
  - major tick: 1 hour (labels at :00 only)
  - minor tick: 10 minutes (grid only)
- Y-axis:
  - min: 0
  - max: ceil(maxCapacity(activeSites)/10000)*10000
  - ticks: 10000 step
  - If activeSites is empty: yMax fallback = 10000 and show empty state.

### Tooltip (hover)
- 2 lines:
  1) `HH:mm`
  2) `{siteId} · {kw} kW ({tmoPct}%)`
- kw: thousands-separated
- tmoPct = (kw / capacityKw) * 100, 1 decimal
- if capacityKw missing/0: hide `(tmoPct%)`

## Tables
### Semi-central table (fixed 4 rows)
Columns (draft):
- chart checkbox, siteId, siteName, capacityKw
- customerOrder, rmccStart, start, finish, maxKw, minKw, cancel

### Non-central table
- maxKw is NOT used.
- baselineKw0900 is displayed (read-only).
- baselineKw0900 rule: nearest point to 09:00, if none => null(—).
Columns (draft):
- chart checkbox, siteId, siteName, capacityKw
- customerOrder, rmccStart, start, finish, baselineKw0900, minKw, cancel

### Cancel
- Means “today schedule is canceled”.
- Canceled site is excluded from "active" list and from non-central group selection.

## Editing & Autosave
- Inline edit per cell.
- Press Enter => autosave (PATCH).
- On success:
  - show row-level `Saved ✓` for 1~1.5s
  - highlight edited cell briefly
  - append system log line
- Log format:
  `[HH:mm:ss] {siteId} {field} : {old} → {new} (user:{optional})`
- Server time (KST) should be used for timestamps in log.

## Roles
- Operator: can edit, add/activate, cancel, export
- Supporter/Viewer: read-only

## Export
- Excel (.xlsx) template generated by backend.
- Should include tables and notes(system logs).
