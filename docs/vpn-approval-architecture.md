# VPN 불가 사용자 환경을 위한 승인 기반 접속 구조

질문: "GPT 실행 환경에서는 사내 VPN 접속이 불가한데, 사용자가 ID/PW를 입력하고 메인 서버(내 PC)에서 승인하면 휴대폰/외부 환경에서도 사용 가능할까?"

## 결론
- **가능합니다.** 다만 핵심은 **VPN/Webview 접속은 중앙 서버(메인 PC 또는 사내 서버)만 담당**하게 설계하는 것입니다.
- 사용자 단말(휴대폰/외부)은 Webview에 직접 접속하지 않고, 중앙 서버의 대시보드/API만 접속합니다.

## 권장 구조
1. 중앙 수집 서버
   - VPN 연결 + Webview 로그인/크롤링 수행
   - 내부 DB에 발전량/이벤트 저장
2. 사용자 접속 서버(API/UI)
   - 인증 후 저장된 데이터 조회
   - CSV/XLSX 다운로드 제공
3. 승인(2단계) 흐름
   - 사용자가 ID/PW로 로그인 요청
   - 운영자(당신)가 승인
   - 승인된 단말만 토큰 발급

## 보안상 중요한 원칙
- 사용자 단말에 Webview 계정(ID/PW)을 절대 저장/전달하지 않기
- 승인 토큰은 짧은 TTL + 기기 정보(device binding) 적용
- 운영자 승인 로그(누가/언제/어떤 기기 승인) 저장
- 가능하면 사내 SSO/OIDC 연동으로 비밀번호 직접 취급 최소화

## 이번 코드에 반영된 데모 API
- `POST /api/auth/login-request`: 로그인 요청 생성(승인 대기)
- `GET /api/auth/pending`: 승인 대기 목록 조회(운영자 화면용)
- `POST /api/auth/approve/{request_id}`: 운영자 승인
- `POST /api/auth/token`: 승인 완료 후 액세스 토큰 발급

> 현재는 동작 데모를 위한 인메모리 저장소입니다. 운영 시 DB/Redis, TLS, 감사로그, JWT 서명키 관리가 필요합니다.
